# KSY DOT TEST
This is online test for gathering data about whether the color or size of dots does have an impact on the estimate of number of dots.

## The test
There are 28 pictures of dots to estimate in total. User is promted to guess the number of dots based on very brief exposure of the picture (500 ms).

## Results

## Images
There are 4 categories of images:
- same color, same size (pictures 01-07)
- different color, same size (pictures 08-14)
- same color, different size (pictures 22-28)
- different color, different size (pictures 15-21)
There are 7 different colours and the dots are in size range of 5 to 25 (10 if all sizes are the same)
